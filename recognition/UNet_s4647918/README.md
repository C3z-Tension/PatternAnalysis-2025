## 🧠 Algorithm Overview & Problem Statement

The **Improved UNet** algorithm is a convolution-based deep learning method that utilizes skip connections to learn both small and large features. It incorporates a **preactivation block** that normalizes and applies an activation function *before* convolution, improving gradient flow during backpropagation.

This model is applied to segment the **2D OASIS brain dataset**, aiming for all labels to achieve a **minimum Dice similarity coefficient of 0.9** on the test set.
